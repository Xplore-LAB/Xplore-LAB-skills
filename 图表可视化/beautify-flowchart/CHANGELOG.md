## 🚀 v2.1.0 - Visio 集成版 (2026-06-05)

### ✨ 新增功能

#### Visio 输出集成

- **Visio 作为最终交付目标** — 在流程图提取和美化的基础上支持导出 `.vsdx`
- **声明式 JSON 图规范** — 推荐 JSON → 渲染器的架构，分离数据与执行
- **Visio COM 自动化** — 基于 Python `pywin32` 的渲染器模式（参考 `deermiya/visio-skill`）
- **基本形状默认** — 流程图默认使用 `roundrect` / `rectangle` / `ellipse` / `diamond`

#### 图片到 Visio 重建

- **两阶段重建工作流** — 裁剪 → 几何重建 → 预览 → JSON → `.vsdx`
- **几何检测** — 矩形、圆角矩形、菱形、水平/垂直线、表格/泳道网格、颜色采样
- **标注叠加** — 对文字密集或视觉复杂的图，用标注叠加替代逐元素重绘

#### Visio 质量模式

- **重构优于复制** — 超过 18 个节点时拆分为概览页 + 子流程页
- **语义分组** — 保留业务逻辑，将重复链、累加器、长异常分支简化为命名子流程框
- **正交连接器** — 禁止对角线，每条连接器走清晰的水平/垂直段
- **分支方向一致性** — 主路径统一方向，拒绝/异常分支向侧面退出
- **可读排版** — 短标题、9-11pt 正文、自动换行、无旋转文字
- **克制配色** — 红/粉(入口/触发)、蓝/灰(处理)、琥珀(判断)、绿(终点/成功)
- **留白** — 图面使用率不超过 70%
- **交付前预览检查** — 连接器不重叠节点、菱形内文字不旋转、标签不碰撞

#### 新增参考文件

- `references/editorial-diagram-style.md` — 编辑级图表风格指南
- `references/logic-validation.md` — 逻辑验证指南
- `references/visio-automation.md` — Visio COM 自动化步骤与脚本模式
- `references/visio-layout-contract.md` — Visio 布局契约规范

#### 快速 Visio 成功经验（Lessons Learned）

1. 保持布局通过保持坐标，不用 Visio 自动布局
2. JSON 规范作为唯一真相源
3. 决策菱形用真正多边形，不用旋转矩形
4. 保持原布局时用手动正交线段替代动态连接器
5. 先生成 `.vsdx`，PNG/PDF 导出可能卡住
6. Windows PowerShell 中文图使用 UTF-8 编码加载脚本
7. PowerShell 几何辅助函数避免数组返回陷阱
8. Visio 锁定旧文件时创建新文件名
9. 首版保守渲染，结构正确后再提升美观
10. 预览导出失败但 `.vsdx` 正常打开时，交付 `.vsdx` 并说明限制

## 🔄 v2.0.0 - 方法论重写 (2026-06-04)

### 💥 重大变更

**从"Mermaid 模式选择器"彻底重写为"方法论驱动的流程图美化与重建框架"**

#### 核心理念变化

| 方面 | v1.x | v2.0.0 |
|------|------|--------|
| **驱动力** | 用户选模式（style/layout/both/smart） | 方法论驱动（提取→分析→选择→执行） |
| **任务分类** | 单一美化 | 图片美化 / 可编辑重建 两大类 |
| **执行保障** | 依赖 AI 判断 | 强制执行六步流程 |
| **交付物** | 仅 PNG | PNG / draw.io / PPT / SVG / Visio |
| **质量保障** | 无 | 验收标准 + 禁止事项清单 |

#### 强制执行六步流程

1. **提取原图内容** — 分区、节点、判断节点、连线、文字、颜色语义、布局关系
2. **输出提取结果** — 结构化摘要 + 不确定性标记（可确认/大概率/无法确认）
3. **读取用户约束** — 布局一致/文字一致/可编辑/交付格式/美化或重建
4. **选择执行路线** — 路线 A（图片美化）或路线 B（可编辑重建）
5. **选择模式** — style / layout / both / smart（smart 受约束降级）
6. **执行** — 严格按选定路线和模式执行

#### 新增概念

- **图片美化 vs 可编辑重建** — 两类任务不能混做，必须先判断
- **文字不确定性标记** — 可确认 / 大概率如此 / 无法确认
- **约束驱动降级** — 用户说"布局完全一致"时 smart→style 强制降级
- **验收标准** — 图片美化结果检查（布局/箭头/分区/颜色语义/遮挡），可编辑重建结果检查（可打开/可编辑/可拖动/结构一致）
- **禁止事项清单** — style 模式禁止重新布局，重建禁止伪装成修图
- **推荐输出方式** — 按场景分类：准确复刻/可编辑版本/布局完全一致

#### 保留并精炼

- 四种模式（style/layout/both/smart）从 v1.1.0 保留，但语义更加精确
- Mermaid 作为中间表示仍可使用，但不再是唯一输出格式

## 🎉 v1.1.0 - 多模式版本 (2026-06-03)

### ✨ 新增功能

#### 四种美化模式

1. **Style 模式（纯样式美化）**
   - 🎨 保持原布局，仅美化外观
   - 🎯 应用专业配色方案
   - 🔷 区分不同类型的节点
   - ⚡ 处理速度快
   - 📌 适用：布局已满意，只需美化

2. **Layout 模式（纯布局优化）**
   - 📐 优化节点位置和排列
   - 📦 使用分组（subgraph）组织相关节点
   - 🔗 减少连接线交叉
   - 🎯 保持原有颜色方案
   - 📌 适用：布局混乱，需要整理

3. **Both 模式（完全美化）**
   - 🚀 同时优化布局和样式
   - 🎨 专业级配色方案
   - 📦 清晰的分组结构
   - 🔷 多样化的节点形状
   - 📌 适用：需要专业呈现，追求最佳效果

4. **Smart 模式（智能美化）⭐ 推荐**
   - 🤖 AI自动分析流程图
   - 🔍 检测布局和样式问题
   - ⚡ 智能选择最佳方案
   - 🎯 针对性优化
   - 📌 适用：不确定需求，快速获得好效果

#### 六种颜色主题

| 主题 | 风格 | 适用场景 |
|------|------|----------|
| `default` | 蓝色商务 | 通用，正式文档 |
| `dark` | 暗色系 | 演示，屏幕展示 |
| `colorful` | 多彩活泼 | 创意，非正式场合 |
| `minimal` | 极简黑白 | 简洁，专业 |
| `business` | 专业商务 | 企业，商业文档 |
| `modern` | 现代时尚 | 现代感，科技风 |

#### 布局方向控制

- `auto` - AI自动选择最佳方向
- `TD` - 从上到下（最常用）
- `LR` - 从左到右（宽屏）
- `TB` - 从上到下（与TD相同）
- `RL` - 从右到左

#### 输出控制

- **尺寸自定义** - 支持指定宽度和高度
- **缩放比例** - 支持1x, 2x, 3x, 4x清晰度
- **背景颜色** - 支持透明、白色、自定义颜色
- **输出文件名** - 支持自定义输出文件名

### ❓ 常见问题

#### Q: 应该选择哪个模式？

A: 如果不确定，使用 `smart` 模式。AI会自动分析并选择最佳方案。

#### Q: 为什么美化后布局变化很大？

A: 使用 `--mode style` 会保持原布局。`both` 模式会同时优化布局和样式。

#### Q: 如何保持原有颜色？

A: 使用 `--mode layout` 只优化布局，保持原样式。

#### Q: 如何获得更高清的图片？

A: 使用 `--scale 2` 或 `--scale 4`。

#### Q: 支持哪些图片格式？

A: 支持 PNG、JPEG、SVG、WebP 等常见格式。

#### Q: 中文显示有问题？

A: 确保系统安装了中文字体（如微软雅黑）。

#### Q: 处理时间太长？

A: 复杂流程图使用 `both` 模式会较慢。可以尝试 `smart` 模式或 `style` 模式。
