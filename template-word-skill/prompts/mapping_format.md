# md_to_template_docx.py 映射文件格式

JSON 格式，定义 Markdown 章节标题到模板锚点文本的映射关系。

## 默认映射

不提供映射文件时，使用以下默认映射：

| Markdown 标题 | 模板锚点文本 |
|--------------|-------------|
| 说明书摘要 | `本发明公开了一种` |
| 权利要求书 | `1. 一种` |
| 发明名称 | `发明名称：` |
| 技术领域 | `本发明属于` |
| 背景技术 | `背景技术` |
| 发明内容 | `本发明的目的在于` |
| 具体技术方案 | `本发明所采用的具体技术方案如下` |
| 有益效果 | `本发明相对于现有技术而言` |
| 附图说明 | `图1为` |
| 具体实施方式 | `如图1所示，` |
| 说明书附图 | `说 明 书 附 图` |

## 自定义映射文件

```json
{
  "我的章节标题": "模板中的锚点文本",
  "摘要": "摘要",
  "方法": "本发明所采用的技术方案"
}
```

映射文件中的条目会**覆盖**默认映射中同名的条目。

## 匹配策略

查找模板锚点时，按以下优先级匹配：

1. **完全匹配**：段落文本 == 锚点文本
2. **包含匹配**：锚点文本 ∈ 段落文本
3. **关键词匹配**：去除标点后，锚点文本 ⊂ 段落文本

## 图片映射

Markdown 中的图片会自动插入到对应章节的锚点位置：

```markdown
![图1](figures/system_arch.png)
<!-- ![图2](figures/flowchart.png) -->
```

- 支持标准 Markdown 图片语法 `![alt](path)`
- 支持 HTML 注释中的图片引用 `<!-- ![alt](path) -->`
- `alt` 以"图"开头时，自动添加居中粗体标签
- 图片路径相对于 Markdown 文件所在目录（可通过 `--fig-dir` 覆盖）
